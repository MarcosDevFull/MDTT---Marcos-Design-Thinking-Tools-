# Marcos Design Tools

Uma jornada visual e interativa pelas fases do Design Thinking para UX/UI.

## Inclui

- 6 fases do processo: Empatia, Definição, Ideação, Prototipagem, Validação e Documentação.
- 10 métodos sequenciais por fase, totalizando 60 métodos.
- Modo Jornada, com a visão infográfica completa.
- Modo Abas, com navegação focada por fase.
- Modais explicativos com como aplicar cada método e seus entregáveis.
- Links para ferramentas recomendadas em cada etapa.

## Como abrir

Abra `index.html` diretamente no navegador. O projeto não precisa de build ou dependências locais.
